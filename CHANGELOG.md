## 1.0.0

* **Initial Release - Modern SMS OTP Autofill**:
    * **Pigeon Integration**: Type-safe platform communication for Android and iOS.
    * **WebOTP Support**: Modern WebOTP API support using `package:web` (WASM compatible).
    * **Material 3 UI**: Modern `OtpField` widget with shake animations and loading states.
    * **Unified API**: Simplified `SmsOtp` and `OtpSession` for easier lifecycle management.
    * **Advanced Diagnostics**: Built-in tools to debug Android autofill status.
    * **Firebase Integration**: `FirebaseOtpField` for seamless Phone Auth support.
    * **Flexible Strategies**: Support for both SMS Retriever API and User Consent API.
